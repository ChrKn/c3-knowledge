# How to achieve all walkers giving the best comments

The following conditions must be met:

- Gods: Happiness ≥ 40% ("displeased" or better)
- Food reserve: ≥ 4-month
- Employment
  - Unemployment rate: < 5% **or**
  - Workers needed: < 10
- Population: ≥ 500
- Avg. entertainment points per house: ≥ 21<sup>1</sup>
- Avg. number of Clinics and Hospitals per house: ≥ 1<sup>1</sup>
- Avg. number of education venues per house: ≥ 1 <sup>1,2</sup>

<sup>1</sup> Arithmetic average rounded down (integer calculation).  
<sup>2</sup> Counted as follows:  
* School **or** Library + 1; 
* School **and** Library + 2; 
* School, Library, **and** Academy + 3
